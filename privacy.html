Privacy policy

This is a personal tool used only by its owner, to connect Claude to the owner's own Google account. No one else signs in to it.

It reads the owner's Gmail and Google Calendar, and sends email only when the owner asks it to. Data stays on the owner's own computers and is never sold, shared, or used for advertising. Use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements.

Access can be removed anytime at myaccount.google.com/permissions.
